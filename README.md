# Python Calorie Tracker

A desktop calorie tracking application built with Python, Tkinter, and JSON.

## Features
- Set and save a daily calorie goal
- Add and remove meals
- Calculate total daily calorie intake
- Track remaining or exceeded calories
- Save meals and goals between sessions using JSON

## Technologies Used
- Python 3
- Tkinter
- JSON

## How to Run
1. Install Python 3.
2. Download `gui.py` from this repository.
3. Open a terminal in the downloaded file's folder.
4. Run:

   `python gui.py`
